A fast, dependency-free CSV reader that reproduces csv-reader 1.0.0's broken-row policy exactly: BOM drop, LF/CRLF line breaks, stray CRs reported and dropped, quoted fields with doubled quotes and line breaks inside, junk after a closing quote, unterminated quotes read back as literal, short and long rows padded or cut to the first record's width, with every break recorded as an error. It reads each file in a single left-to-right pass, taking plain fields and clean quoted fields with one slice each, and only walks character by character for the rare broken shapes.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
